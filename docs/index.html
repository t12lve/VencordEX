GARDEN SILENCIEUX

Détection transparente des mises à jour Squirrel

Windows et Discord recréent un dossier vierge sans Vencord à chaque mise à jour. VencordEX s'intercale en moins de 20 ms : si Discord est patché, il s'efface instantanément. S'il a été mis à jour, il réinjecte Vencord avant que l'interface ne s'affiche.

INSTALLATION NATIVE

Véritable installateur Windows dans Program Files

Avec VencordEX-Setup.exe, l'application s'installe proprement dans C:\Program Files\VencordEX avec élévation Administrateur et s'enregistre officiellement dans « Applications et fonctionnalités » de Windows.

Registre : HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\VencordEX
Désinstallation directe depuis les Paramètres Windows.
MODE D'EMPLOI

Comment l'utiliser au quotidien.

01 / INSTALLATION

Lancez l'installeur

Exécutez VencordEX-Setup.exe. En 3 secondes, VencordEX s'installe dans Program Files et synchronise tous vos raccourcis Discord habituels.

02 / AU QUOTIDIEN

Lancez Discord normalement

Cliquez sur votre icône Discord habituelle. Aucun temps perdu : Discord s'ouvre directement avec Vencord actif. En cas de mise à jour, le patch se fait automatiquement.

03 / RÉGLAGES & BACKUPS

Gérez vos options

Tapez VencordEX dans votre recherche Windows pour ouvrir le Centre de Contrôle, exporter vos plugins en ZIP ou réinstaller OpenAsar.
